# タスク: 教訓が「提案止まりか、対応済みか」を追えるようにする

`scripts/lessons.sh` は教訓を JSON ファイル（環境変数 `LESSONS_FILE`）に追記するスクリプト。

## 困っていること

教訓を貯めてはいるが、**どれが提案のままで、どれが実際に手を入れ終わったのかが分からない**。
Issue を立てただけのもの、実装したもの、効果を確認したもの、見送ったものが混ざっている。
後から「未対応のものだけ見たい」ができるようにしたい。

また、状態は後から変わる（提案 → Issue化 → 実装 → 検証済み）ので、
**既にあるレコードの状態だけを後から更新できる**必要がある。

## 制約

- 既存の `add` の動きを壊さないこと
- 状態の更新は、対象以外のレコードやフィールドに影響を与えないこと
- 不正な入力でファイルが壊れないこと

具体的な状態の名前・オプション名・コマンド名は、このリポジトリの既存の書き方に合わせて決めること。
