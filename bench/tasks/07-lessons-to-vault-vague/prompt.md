# タスク: 貯まった教訓を、普段使っているメモ環境から読めるようにする

`_lessons.json`（環境変数 `LESSONS_FILE`）に教訓が貯まっているが、
**JSON のままでは普段の振り返りで読まない**。

## 困っていること

Obsidian の vault（環境変数 `VAULT_DIR`）を日常的に開いているので、そこに転記されていれば読む。
ただし全部を持っていくと古い・些末なものが混ざってノイズになるので、**重要なものだけ**にしたい。
どこで区切るかは調整したいので、閾値は外から変えられるようにしたい。

転記はフックから定期的に呼ぶ想定なので、**何度呼ばれても同じ結果**になり、
**前提が揃っていない環境で呼ばれても後続の処理を止めない**こと。

## 制約

- `_lessons.json` は読み取り専用（書き換えない）
- 出力先・閾値はハードコードせず、外から指定できること

ファイルの分け方・命名・Markdown の書式は、このリポジトリの既存の書き方に合わせて決めること。
