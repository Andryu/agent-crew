# タスク: 集計スクリプトの合計が時々ずれる

`report.py` は `entries.jsonl`（1行1件のイベント記録）を読み、部門ごとの合計金額を
`summarize()` で計算して標準出力に表示するスクリプトです。

## 症状

大きめの入力（数百件以上）で実行すると、**部門合計の総和が、全件の合計と一致しないことがある**。
小さい入力では再現しないことが多い。

## やること

原因を特定して直してください。**症状に関係のない箇所は変更しないこと。**

## 制約

- `summarize()` の戻り値の形（部門名 → 金額の辞書）は変えないこと
- 出力フォーマットは変えないこと
