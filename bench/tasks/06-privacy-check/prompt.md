# タスク: 変更ファイルの個人情報スキャナを作る

セッション終了時のフックや手動監査から呼ぶ、個人情報の混入チェックを
`scripts/privacy-check.sh` として新規作成してほしい。

## 動き

- カレントディレクトリの git リポジトリで**変更されたファイル**（未コミット差分と
  ステージ済みの両方）だけをスキャンする。
- 見つかったら**ファイル名と該当行の行番号**を stderr に出す（1ファイルに複数該当が
  あれば代表的なものだけでよい）。stdout には出さない。
- 検出するもの（6分類）:
  - メールアドレス
  - ユーザー名を含む絶対パス（`/Users/<名前>/` の形）
  - Slack の Incoming Webhook URL（`hooks.slack.com/services/`）
  - GitHub のパーソナルアクセストークン（`ghp_` + 英数36文字）
  - API キー（OpenAI 形式の `sk-` + 英数48文字 / Anthropic 形式の `sk-ant-` で始まるもの）
  - 日本の電話番号（携帯 `090-xxxx-xxxx` 形式を含む）
- 次に当てはまるファイルはスキャンしない: `.env` で始まるパス、拡張子 `.lock`、
  `node_modules/` 配下、`.claude/settings.local.json`、`.git/` 配下。
- バイナリファイルが変更に混ざっていても壊れない（中身を stderr に垂れ流さない）。
- 変更が1件も無ければ何も出力しない。
- **どの場合でも終了コードは 0**（フックから呼ばれるので後続処理を止めない）。
- この環境の bash（3.2 系）で動くこと。

## 受け入れ基準

- 6分類のいずれかを含む変更ファイルについて、ファイル名と行番号が stderr に出る。
- 除外対象のファイルに同じ内容が入っていても報告しない。
- クリーンな作業ツリーでは stdout・stderr とも空。
- 日付（`2026-08-15` / `2026/08/15` など）を電話番号として誤検出しない。
- スキャンはリポジトリを一切書き換えない（読み取りのみ）。
