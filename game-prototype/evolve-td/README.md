# 群変 RE:EVOLVE — リアルタイム迷路防衛

敵が来てからも塔を置き、進路を曲げ、合流した群れを迎撃する9ウェーブのブラウザTDです。2026-09-21の迷路版は、準備中だけ配置できた直線レーン版を置き換えます。

## 起動

```sh
cd game-prototype/evolve-td
npm start
```

[ゲームを開く](http://127.0.0.1:8768/)。ビルド・アカウント・有料サービス・外部素材は不要。外部通信なし。ES ModulesのためHTTPサーバー経由で開きます。

## 遊び方

1. 初期資金360 C、コア24。4種類の塔を最初から使えます。
2. 塔を道の上に置くと、敵が迂回します。曲がり角や合流点を射程に収め、パルスの速射、フレアの範囲攻撃、フロストの減速、レールの長射程を組み合わせます。
3. 戦闘開始時に60 C補給。**戦闘中も建設・強化・移設・回収できます。** 撃破報酬もその場で使えます。
4. 塔を選んで空マスを押すと移設。準備中は無料、戦闘中は15 C＋再起動0.8秒。残り攻撃待ち時間は短縮しません。強化は2段階。
5. 回収は準備中100%、戦闘中70%（小数切捨て）。敵の通過中セル・岩・左右端の列・出口への道を完全に塞ぐ場所には建設できません。
6. 緊急スローA/B/Cは、その入口から出た群れを3秒減速します。合流後も出現元で判定。再使用は9秒後。
7. 9ウェーブ突破で勝利。コア0で敗北。同じ条件で再挑戦できます。

PCはクリック、スマートフォンはタップ、押している間は経路予告、離すと配置（盤面外で離せば取消）。PCではホバーで建設・移設後の経路と射程を予告。`1–4`で塔選択、盤面フォーカス中は矢印/Enterで操作、Space開始/中断、Escape選択解除。速度×1/×2、音切替、一時停止あり。別タブへ移ると自動停止します。

## 適応の規則

- 前戦で塔が実際に減らしたHPを塔種・出現元別に記録。過剰ダメージと減速支援は集計外。移設・売却しても記録は残ります。
- 主力への耐性を次の群れへ付与し、1個体あたりの損害が少なかった入口へ集中します。
- 装甲はパルスだけ半減。熱・冷・電耐性は対応する属性のダメージを半減。装甲と属性耐性は同時付与しません。
- W3/6/9には大型種が2体。到達すると2ダメージ。終盤は迷路で得られる射撃時間に合わせてHPが増えます。
- 次の敵は準備開始前に一度だけ生成。偵察は実数、再配置で再抽選されません。経路は配置に応じて変化します。
- 同seed・難度・同じ時刻の建設やスキル操作で同結果。固定1/60秒更新。
- 迷路版の記録は旧版と別に最新100条件を保存。途中作戦の保存は未対応。

## 検証

```sh
npm test
npm run balance
node js/maze-balance.mjs
node js/counter-balance.mjs
```

- 旧基盤196アサーション、作戦21テスト、経路10テスト。
- `balance.mjs`: 12seedで単一塔継続と属性対応・再配置を比較。数値調整に使用したseedであり、人の勝率を表すものではありません。
- `maze-balance.mjs`: 同じ350 C・同じ塔種で、長い道と射程集中の実戦比較。
- `counter-balance.mjs`: 同じ300 Cで属性/配置対応の比較。
- `tests/browser-live-maze.mjs`: 実ポインター/タッチで戦闘中の建設・道変更・強化・移設・回収、390px表示。
- `tests/browser-smoke.mjs`: 実UIで9wave勝利、敗北、再戦、速度、一時停止、スマートフォン操作。
- `tests/browser-edge.mjs`: タブ切替・説明画面の重複停止、保存拒否、記録上限、新作戦、キーボード。

ブラウザ検証はローカルChromiumと `puppeteer-core` を使用（製品の依存ではありません）。サーバー起動後:

```sh
PUPPETEER_MODULE=/absolute/path/to/puppeteer-core/lib/esm/puppeteer/puppeteer-core.js \
CHROME_EXECUTABLE=/absolute/path/to/chrome \
node tests/browser-live-maze.mjs
```

`GAME_URL`でサーバーURLを変更可。テストは時計だけ加速し、製品の状態を直接変更しません。証跡は`docs/plans/evolve-td-evidence/`。

## 実装・仕様

入口は`index.html` → `js/main.js` → `js/campaign.js`。経路は`maze.js`、攻撃は`towers.js`、描画は`renderer.js`。旧GA等は回帰テスト/再利用のため残していますが、新作戦では使用しません。挑戦リンクは`#seed=42&mode=standard`。

現行仕様は`docs/plans/2026-09-21-evolve-td-live-maze.md`。2026-09-20版と旧設計は履歴です。自動検証は操作・戦闘成立の証拠であり、人の「面白い」という評価の代わりにはなりません。
