## MVP 定義（承認されたら以降の How は全面委任）

### 投資部門 MVP
- **内容**: alpha-predict-jp の蓄積データから、ベンチマーク比の統計的優位性を検証した**月次成績レポート**（予測精度・仮想損益・特筆シグナル・ベンチマーク比較）を自動生成し、経営会議キューに自動掲載する
- **オーナーの用途**: L1 判断材料。ベンチマークを継続的に上回れば**実資金配分の検討材料に格上げ**、下回れば部門アイドル化を検討する明確なシグナルとして機能させる。**実売買の執行は L0 のまま人間**（憲章第1条を変更しない）
- **撤退基準**: 「レポートが3ヶ月連続でオーナーの判断に使われなかった」または「3ヶ月連続でベンチマークを下回った」場合、部門をアイドルに戻し教訓化

### ダッシュボード MVP（確定済み・ADR-016）
- 実スプリントをおおむね2秒以内遅延で反映し、オーナーがターミナルを開かずスプリントを追える

### 動画部門 MVP（暫定案・Step 3 の Go 判断時に確定）
- **内容**: AI の強みを活かした動画1本を企画→制作→公開まで通し、視聴データという定量シグナルを得る
- **成功指標（暫定）**: 公開後の再生数・エンゲージメント率が、O2 KR2.3 のリサーチ段階で検証した競合実データの水準に対して有意な水準に達するか
- **オーナーの用途**: L1 判断材料。Step 3 の Go/No-Go 判断（憲章第2条、8月中旬）を経て本開設するかを決める。**公開操作は L0（オーナー実行、憲章第1条を変更しない）**
- **撤退基準（確定 v1.1）**: Go後、最初の動画公開から**3ヶ月**で視聴データが KR2.3 で検証した仮説の水準を明確に下回り続けたら部門をアイドルに戻し教訓化（実例2件の「2〜3ヶ月無反応→伸長」パターンに基づき、2026-08-03 の開設ゲートでオーナーが1ヶ月→3ヶ月へ修正承認。1ヶ月時点はエンゲージ先行指標によるピボット判断のみ）

### ゲーム部門 MVP（2026-08-04 オーナー判断により本開設。アクティブ）
- **内容**: ゲームコンセプトのリサーチを行い、そこから絞り込んだ1コンセプトのプロトタイプを最低1本試作する（オーナー指摘、2026-08-02: リサーチだけでなくプロトタイプまでH2内で着手する）
- **成功指標（暫定）**: プロトタイプが実プレイテストで一定の反応（継続意向・満足度等の定性・定量シグナル）を得られるか
- **オーナーの用途**: L1判断材料。プレイテストの実データで「継続するかアイドルへ戻すか」を判断する
- **開設（v1.2 改訂）**: 当初は「アクティブ化は2027年判断のまま」としていたが、プロトタイプ「巡室」が完成し
  プレイテスト段階に入ったため、**2026-08-04 にオーナー判断で本開設**した（4部門並行体制）。
  部門憲章 `docs/org/charters/game-dept-charter.md` v1.0 を起案・有効化済み。
  **判定期日は 2027年ではなく 2026-09-30**（憲章の撤退基準）に前倒しされた
- **撤退基準（憲章 v1.0）**: 2026-09-30 時点で有効回答10件未満、または継続意向30%未満/平均2周未満ならアイドルへ戻す
- **時期**: Step 4（8月中旬〜下旬）に着手済み。プロトタイプ実装完了（PR #171）、プレイテスト回収へ
