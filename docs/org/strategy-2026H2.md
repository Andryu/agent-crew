## MVP 定義（承認されたら以降の How は全面委任）

### 投資部門 MVP
- **内容**: alpha-predict-jp の蓄積データから、ベンチマーク比の統計的優位性を検証した**月次成績レポート**（予測精度・仮想損益・特筆シグナル・ベンチマーク比較）を自動生成し、経営会議キューに自動掲載する
- **オーナーの用途**: L1 判断材料。ベンチマークを継続的に上回れば**実資金配分の検討材料に格上げ**、下回れば部門アイドル化を検討する明確なシグナルとして機能させる。**実売買の執行は L0 のまま人間**（憲章第1条を変更しない）
- **撤退基準**: 「レポートが3ヶ月連続でオーナーの判断に使われなかった」または「3ヶ月連続でベンチマークを下回った」場合、部門をアイドルに戻し教訓化

### ダッシュボード MVP（確定済み・ADR-016）
- 実スプリントをおおむね2秒以内遅延で反映し、オーナーがターミナルを開かずスプリントを追える

### 動画部門 MVP（暫定案・Phase C の Go 判断時に確定）
- **内容**: AI の強みを活かした動画1本を企画→制作→公開まで通し、視聴データという定量シグナルを得る
- **成功指標（暫定）**: 公開後の再生数・エンゲージメント率が、O2 KR2.3 のリサーチ段階で検証した競合実データの水準に対して有意な水準に達するか
- **オーナーの用途**: L1 判断材料。Phase C の Go/No-Go 判断（憲章第2条）を経て本開設するかを決める。**公開操作は L0（オーナー実行、憲章第1条を変更しない）**
- **撤退基準（暫定）**: Go後、最初の動画公開から1ヶ月で視聴データが KR2.3 で検証した仮説の水準を下回ったら部門をアイドルに戻し教訓化

### ゲーム部門 — 対象外（H2スコープ外）
- **状態**: 未開設。**2027年に開設判断**（`docs/org/departments.md`）
- **理由**: 全プロジェクトは着手前にプロジェクト憲章が必須（憲章第4条「憲章なき着手は禁止」）。ゲーム部門はまだ憲章起案前であり、2026H2のロードマップ（Phase A〜D）には含めない
- **本H2での扱い**: リサーチ・企画着手なし。Phase D「H2総括と2027計画」で扱いを再検討する
