# 投資部門 Go/No-Go 事前検証レポート（調査エージェント、2026-08-02）

**結論**: コストは論点にならない（データAPIは全て無料、Claude増分は月$1〜4）。争点は「憲章が計測すると宣言した TOPIX 比較が、現在のデータでは1ヶ月分も計算できない」こと。加えて、唯一ゲートを通過した60日シグナルのフォワード検証日数はゼロ、本番の5日シグナルのフォワードICは -0.30（NW t=-6.16、13日）で有意に負。

## 1. 競合差別化判定

**判定: 「AIによる日本株予測+レポート自動生成」という粒度では差別化は成立しない。ただし alpha-predict-jp は外販プロダクトではなくオーナー個人の意思決定支援であり、tabi-canvas と同じ基準は適用外。**

- moomoo証券「AI銘柄分析」が日本株対応済みで日次・週次AIレポートを無料配信。AIチャート予測・決算要約も無料
- カブチャレが AI相談＋バックテスト＋学術ファクター投資を無料提供
- 海外では「個人の相場観を投資可能な配分に変換し自律実行する」AIポートフォリオエージェントが商用化済み
- 市販品に見当たらないのは予測精度の統計的検証（IC・Newey-West・ベイズ劣化監視）とベンチマーク超過の継続計測だが、これは「売れる差別化」ではなく「自分の判断を検証可能にする計器」
- **No-Go の理由になり得るのは競合ではなく「成績が出ないこと」であり、現時点の観測は負の兆候**

## 2. APIコスト概算

- 現行データAPI: yfinance / EDINET / Wikipedia / JPX — **全て無料**
- 月次レポート自動生成の増分: 集約はコード側・Claudeは解釈と文章化のみの設計で**月 $1〜4**（invest部門消費の1〜4%上乗せ）
- ⚠ 生の予測JSON 106ファイルを Claude に読ませる設計にすると入力が10倍以上に膨張。集約はコード側が前提
