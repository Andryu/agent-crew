# Go/No-Go ゲート: 動画部門開設（戦略 v1.0 Step 3）

> 種別: **Go/No-Go**（経営事項・組織憲章第2条）
> 参照: [Step3リサーチ](materials/2026-08-video-step3-research.md) / [動画部門憲章 v0.1](../charters/video-dept-charter.md) / [戦略2026H2](../strategy-2026H2.md) / [部門ポートフォリオ v1.1](../departments.md)

## 1. 決めること

動画部門を「未開設」から「アクティブ」へ遷移させるか。Goの場合、**撤退基準を1ヶ月（戦略暫定）のまま確定するか、3ヶ月（憲章提案）に修正するか**も併せて決める必要がある（MVP暫定記載の修正＝経営事項）。

**選択肢**
- **(A) Go — 仮説Bで開設、撤退基準を3ヶ月に修正**
- **(B) Go — 撤退基準は戦略暫定どおり1ヶ月**
- **(C) No-Go / 保留**

## 2. Rinの推奨

**(A) を推奨。** 実データ2件（Neural Viz・nick_ai note）がいずれも「最初の2〜3ヶ月はほぼ無反応、3ヶ月目以降に伸びる」という同一パターンを示しており、1ヶ月判定は成功しうる企画を誤って早期撤退させるリスクが高い。1ヶ月基準は"仮説Bなら勝てる"という判断の土台になった実データそのものと矛盾するため、材料に忠実な結論は3ヶ月化。ただし1ヶ月時点のエンゲージメント先行指標によるピボット判断（撤退ではない）は維持する設計になっており、早期の異常検知は失われない。

## 3. 判断材料の要約

- **仮説B（勝てる根拠）**: Neural Viz 23.8万登録・週次更新・月$100+週12時間の低コスト構造。日本語実例（nick_ai）は7月開設→3ヶ月目から伸長→翌1月に3万人。ただし優位性の本体は脚本・世界観という人間側設計（AI生成力そのものではない）。
- **仮説C（明確な反証）**: 量産型コンテンツ規制で日本100チャンネル調査中の収益化停止最多理由が「再利用コンテンツ」（42件／327件分析）、YouTubeはAI slop理由で16チャンネル・47億再生分を削除済み。「量産」を狙う設計は規制の主標的。
- **プラットフォーム条件**: TikTok Creator Rewards ProgramはAI生成コンテンツを明示的に排除→主戦場はYouTube Shorts。3プラットフォームとも「AI利用自体」でなく「量産性・独自性欠如」が規制対象で、仮説B（低頻度・強い世界観）は該当しにくい。
- **EP01教訓との整合**: 人間味の本体は声と脚本という結論と、仮説Bの脚本・世界観＝人間主導という役割分担は矛盾しない。むしろこの教訓が仮説Bの設計そのものを裏づけている。

## 4. 各選択肢で起きること

**(A)(B) Go の場合の8月内作業**
- 部門開設手順（部門ポートフォリオ第4条）に従い、新規リポジトリが必要（組織OSテンプレート複製＝ADR-014 Phase 3前提）。既存2部門（プロダクト/agent-crew、投資/alpha-predict-jp）とは別リポジトリになる。
- 初回公開はGo判定後2週間以内（8月中旬Go→8月下旬公開目標）。
- **3部門並行状態への言及**: プロダクト部門はアクティブ、投資部門はStep2ゲート次第（アイドルなら人間稼働ほぼゼロ）、動画部門が加わるとGo後は実質2〜3部門が同時に人間の判断・作業を要求しうる。特に動画は「公開操作がL0＝オーナー実行」（憲章第1条を変えない設計）のため、週1本ペースで脚本レビュー＋公開操作という**新規の定常オーナー作業**が発生する。KR1.2（週90分以内）の余力に対する圧迫要因として経営会議で継続監視すべき論点。
- (A)(B)の差分は撤退判定日のみ。中間ピボットチェック（1ヶ月・視聴維持率）は両案共通で変わらない。

**(C) No-Go/保留の場合**
- KR2.3（少なくとも1つの仮説を実データ検証し開設判断材料を提出）自体はStep3リサーチで既に満たされているため、リサーチのやり直しは不要。ただし「開設判断」自体が下りないため、O2の該当実績は「検証済み・未開設」で足踏み。
- 動画部門は「未開設」のまま据え置き、戦略ロードマップStep4（動画部門立ち上げ）は不発。2027年計画への持ち越し検討が必要になる。

## 5. 門番チェック

- **憲章添付**: `docs/org/charters/video-dept-charter.md` v0.1 Draft添付済み。事前検証チェック5項目中4項目済み、残り1項目（撤退基準1ヶ月 vs 3ヶ月の合意）が本ゲートでの確定待ち＝欠落ではなく設計どおりの保留。
- **撤退基準の保留状態の明示**: 憲章内で「⚠論点（ゲートで要確定）」として明記済み。本ゲートが未確定を解消する場である旨、上記選択肢(A)/(B)で選択を求めている。
- **戦略v1.0との差分**: 戦略2026H2の「動画部門MVP（暫定案）」は撤退基準を「公開1ヶ月」と記載（Approved v1.0本文）。(A)を選ぶ場合はこのMVP暫定記載自体の修正を伴い、戦略文書という経営レベル文書への変更のため、team-leadの実務判断では処理できずオーナー判断が必須の項目として本ゲートに乗せている。
- **部門ポートフォリオ第3条（横展開トリガー）との関係**: 同条は「新部門アクティブ化」を意思決定キューに乗せる一般条件を定めるが、投資→動画→ゲームの個別順次Go/No-Go自体は戦略v1.0のロードマップとしてオーナーが既に承認済み（上位の戦略判断）。本ゲートはその個別実行にあたるため差し戻し対象ではないと判断。念のため経営会議で確認いただきたい。
