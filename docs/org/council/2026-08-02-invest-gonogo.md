# 投資部門アクティブ化 Go/No-Go ゲート 2026-08-02

## 要判断（オーナーのアクションが必要）

### 1. 投資部門（alpha-predict-jp）のアクティブ化 [種別: Go/No-Go]

**決めること**: 以下3案からどれを選ぶか。

- **(A) 範囲限定Go** — 8月内に「月次レポートパイプライン構築＋TOPIX代理（1306.T）バックフィル」のみを実装。成績（ベンチマーク超過）判定は3ヶ月後の別ゲートに分離。憲章v0.2をv0.3へ改訂し、撤退基準を Phase1（レポートが判断に使われるか）/ Phase2（ベンチマーク超過するか）の2段階に明記する。
- **(B) 保留** — 本番5日シグナルのフォワードICが正転するまでGo判定自体を先送り。
- **(C) No-Go** — 投資部門はアイドル継続。

**Rinの推奨**: **(A) を、憲章v0.3改訂を条件に承認**。理由は3点。
1. 選択肢Aは「成績で勝てるか」を問わず「レポート基盤ができるか」だけを検証するスコープであり、5日シグナルのフォワードICが -0.30 と有意に負である事実（後述）はAの妨げにならない。むしろ早く基盤を作り、負けているシグナルを可視化できる状態にすること自体がオーナーのL1判断を助ける。
2. 憲章v0.2はそのままだと矛盾する（門番チェック参照）。v0.3改訂を承認の条件とする。
3. (B)は「正転を待つ」までKR1.1・KR2.1の計測起算ができず、strategy-2026H2 の「8月内に実作業を完結させる」方針と衝突する。負転の解消時期は不明で、実質的な無期限延期になりうる。

**放置した場合**: 投資部門はアイドルのまま、strategy-2026H2 Step2が停滞し、Step3（動画）以降の8月内スケジュールにも波及する。KR1.1（2部門並行運営4週間）の起算が始められない。

## 判断材料の要約

**横展開トリガー充足状況**: ①組織OSテンプレート分離済み＝済 / ②週次経営会議2回連続で意思決定キューのみ＝織り込み判定（材料未確定） / ③現アクティブ部門2連続ゲート到達＝2/2

**差別化判定**: 「AI日本株予測＋レポート自動生成」の粒度では moomoo・カブチャレ等の無料サービスと差別化不成立。ただし alpha-predict-jp は外販プロダクトではなくオーナー個人の意思決定支援であり、tabi-canvas と同一の差別化基準は判定軸としない。No-Goの理由になり得るのは競合の有無ではなく「成績が出ないこと」。

**コスト**: 現行データAPI（yfinance/EDINET/Wikipedia/JPX）は全て無料。月次レポート生成の増分は月$1〜4（invest部門消費の1〜4%上乗せ）。コストは論点にならない。

**ブロッカー3件**:
1. TOPIX時系列が未収集。`^TPX` は yfinance で取得不可を実測済み、1306.T（TOPIX ETF）代理が唯一の現実解。スキーマ変更＋バックフィル＋日次パイプライン組込みが必要。
2. 唯一ゲートを通過した60日シグナル（IC+0.023）のフォワード検証日数がゼロ（開始2026-07-17、60営業日未経過）。
3. 本番5日シグナルのフォワードICが **-0.30（NW t=-6.16、13日）** と有意に負。サンプルは短く確定的ではないが、検証時点とは逆方向。

**二重基準問題**: モデルの教師ラベル・内部評価はN225超過で定義されている一方、レポートのベンチマーク比較はTOPIX（1306.T代理）で行う設計になる。この二重基準（モデル内部=N225／レポート表示=TOPIX）を憲章に明記しないと、後で「何と比べて勝った/負けた」の基準が食い違う。

## 選んだ場合に起きること

**(A) を選んだ場合**: 8月内の作業は alpha-predict-jp 側の新規スプリント（TOPIX代理バックフィル＋月次レポートパイプライン実装）として発生する。これは投資部門の初回スプリント運営＝2部門並行運営の開始を意味し、この時点からKR1.1（2部門並行運営4週間継続）の計測が起算される。同時に憲章v0.3改訂（Phase1/Phase2の段階化）が前提条件になる。

**(B) を選んだ場合**: フォワードICの正転時期は不明であり、事実上の無期限延期になりうる。KR1.1・KR2.1の計測起算が遅れ、strategy-2026H2 ロードマップの「実作業は8月内完結」方針と衝突する。Step3（動画）・Step4（ゲーム）は投資部門と独立に進行可能だが、O1（複数部門運営基盤の実証）の進捗はここで足踏みする。

**(C) を選んだ場合**: KR1.1の達成手段が現状存在しなくなり、strategy-2026H2のO1見直しが必要になる。
