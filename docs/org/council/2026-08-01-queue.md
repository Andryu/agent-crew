# 意思決定キュー 2026-08-01（第1回週次経営会議）

## 要判断（オーナーのアクションが必要）

### 1. Sprint-25 のテーマを「組織OS Phase 2（テンプレート物理分離）」にするか [種別: Go/No-Go]
- **決めること**: ADR-014 Phase 2（部門テンプレートの実体作成 + install.sh への本社機能配布関数追加）を次スプリントで着手してよいか。
- **材料**: ADR-014 に「Phase 2 は本スプリントのスコープ外、別スプリントで Riku に委譲」と既定路線として明記済み。横展開トリガー条件①（テンプレート分離）の充足条件そのもの。project-charter は新規事業でなく既存 ADR の段階実行のため不要と判断（憲章第4条の対象外）。
- **Rinの推奨**: 承認 — 既定路線でスコープが明確、投資部門アクティブ化に向けた構造的前提のため着手価値が高い。
- **放置した場合**: 横展開トリガー①が恒久的に未充足のまま、投資部門アクティブ化の検討自体が始まらない。

### 2. レトロのIssue起票推奨8件の一括承認可否 [種別: その他]
- **決めること**: `sprint-24-retro.md`「Issue起票推奨」節の8件（うち5件は `gh issue create` がauto mode分類器にブロックされ手動待ち）を起票してよいか。
- **材料**: 8件すべて内部運用改善（負荷分散計算・QA横断チェック・レトロ運用等）で公開リスクなし。個別選別による判断コストが効用を上回らない規模。
- **Rinの推奨**: 一括承認 — 全件低リスクの内部改善で、選別コストに見合わない。
- **放置した場合**: 改善提案がIssue化されず、次スプリント計画への可視性が下がる（pm-learned-rules.mdへの反映のみに留まる）。

### 3. Phase 2 とダッシュボード実データ接続、どちらを先にするか [種別: その他]
- **決めること**: Sprint-25 のフォーカスを Phase 2（上記#1）とダッシュボード実データ接続（保留中タスク#1: hooks→ダッシュボード配線）のどちらにするか。
- **材料**: ダッシュボードは可視化改善で意思決定に非直結。Phase 2 は横展開トリガー①の充足条件であり構造的な機会損失が大きい。両方採用も規模次第で可能（Yuki判断領域）。
- **Rinの推奨**: Phase 2 優先 — 横展開という組織全体の前提づくりを可視化改善より優先すべき。
- **放置した場合**: Sprint-25のテーマ不在のままとなり、Yuki の計画着手がオーナーの追加指示待ちで止まる。
