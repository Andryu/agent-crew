## 1. MVP定義（何を作れば「検証できた」と言えるか）

- **仮説B「キャラクター/世界観固定連投型」**（Step 3 リサーチで唯一「勝てる根拠」が実データ確認された企画軸）に基づく、
  実写に寄せないシリーズを**週1本・1〜3分・横型（16:9）の通常動画として継続公開**し、視聴データという定量シグナルを得る。
- **シリーズは『絶滅ハローワーク』**（案C、2026-08-07 オーナー選択）— 絶滅した生き物が現代で再就職の面接を受ける。
  「特技は？」＝形態的特徴、「前職は？」＝生態的地位、「なぜ辞めた？」＝絶滅要因という形で、
  **面接というフォーマット自体が教育的内容を運ぶ**。登録者14万人でも「教育的価値なし」で90日収益化停止された
  実例（きびまら）への構造的な答えとして選択した。
- 役割分担は EP01 の教訓に従う: **脚本・世界観・声の方向性は人間（オーナー）側主導**、AI は生成・演技・編集実務（L2）。
- **公開操作は L0（オーナー実行）**。組織憲章第1条を変更しない。
- 検証点: 「AI の強みに寄せた企画設計で、実データ由来の成長曲線に乗れるか」。

## 2. 成功指標（数値で3つまで — Step 3 リサーチの実データ由来）

| 指標 | 目標値 | 計測方法 | 計測タイミング |
|------|--------|----------|----------------|
| 継続公開 | 週1本を12週連続（人間の作業はオーナーの脚本レビュー・公開操作のみに収束） | 公開実績 | 週次 |
| 登録者 | **3ヶ月で1,000人**（収益化ライン。参考実例: 3ヶ月目以降に伸長開始） | チャンネル分析 | 月次 |
| エンゲージメント | 実データ検証した competitor 水準に対し有意（詳細目安は Step 3 リサーチ成果物参照） | 視聴維持率・エンゲージ率 | 月次 |

## 3. 撤退基準（Kill Criteria）

- **公開開始から3ヶ月**で登録者・視聴データが目安値の水準に対し明確に下回り続けた場合、部門をアイドルへ戻し教訓化。
  - **確定（2026-08-03 ゲートにて）**: オーナーが選択肢Aを承認し3ヶ月で確定。戦略側も v1.1 で整合済み。
- 中間チェック: 1ヶ月時点でエンゲージメント（視聴維持率）だけを先行指標として確認し、企画の微修正（ピボット）判断に使う（撤退判断には使わない）。
- プラットフォーム規制リスク: 量産型検出（台本類似・テンプレ重複）に該当しない設計を維持する。該当警告を受けた場合は即時停止しオーナーへ報告。

## 5. 事前検証チェック

- [x] 競合のAI機能・実データを確認した（Step 3 リサーチ: `docs/org/council/materials/2026-08-video-step3-research.md`。仮説Bに勝てる根拠、仮説Cに明確な反証） 
- [x] プラットフォーム条件を確認した（AI利用自体でなく量産性が規制対象。TikTok Creator Rewards は AI 生成を排除）
- [x] **出力フォーマットを確定した（v1.2, 2026-08-07 オーナー判断）: 主戦場は YouTube の「通常動画」（横型16:9）**。
      YouTube は 2024-10-15 以降、アスペクト比と尺で機械的に分類し投稿者は選べない（縦型かつ3分以内＝必ず Shorts）。
      収益化到達条件は Shorts が90日で1,000万再生、通常動画が12ヶ月で4,000時間であり、
      **本憲章の成功指標「3ヶ月で登録者1,000人」の参考実例（nick_ai）は通常動画側の実例**であるため、
      根拠と経路を一致させる。v1.0〜v1.1 の「主戦場は YouTube Shorts」表記はこれを撤回する
- [x] 撤退基準にオーナーが合意した（2026-08-03 ゲートで3ヶ月に確定）
- [x] コスト概算: 参考実例は月$100規模のサブスク＋制作時間。既存契約範囲を超える新規課金が必要になる場合は L0 でオーナー確認
