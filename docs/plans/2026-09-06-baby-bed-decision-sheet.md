## 3. 元シートへの修正方針

- **追加(7)**: 里帰り出産、上の子・ペット、第2子予定、保管スペース、引越し予定、寝室の床材、扉の開口幅（数値）
- **構造変更**: 「物理的事実（1つの正解がある）」と「価値観（夫婦で割れてよい）」を分離。前者は共有、後者は各自回答してズレを検出
- **統合(1)**: 元Q20とQ21（使用期間）は同義のため統合
- **重み下げ(1)**: 元Q34「頭の形」→ ベッド選定への寄与は小さい。枕不使用の注意喚起に置換
- **数値化**: 元Q3(大人ベッド高)、Q10(設置スペース)、Q16(扉幅) を自由記述から数値入力へ（制約フィルタの入力にするため）

## 4. 判定エンジン

1. **ハードフィルタ**: 設置幅 / 扉開口幅 / 大人ベッド高と床板高レンジの重なり → 物理的に置けない・通れない候補を除外
2. **スコアリング**: 回答 → 7つのベッドタイプへ重み加算
3. **優先度TOP3** で最終補正
4. **レンタル/購入**: 使用期間 × 第2子予定 × 保管スペース × 許容額 で損益分岐を提示
