# 群変: リアルタイム迷路防衛への再設計

mode: Codex direct / complexity L / risk medium
worktree: `.worktrees/evolve-td-reimagined` / branch `codex/evolve-td-reimagined`

## 出発点
ユーザー評価: 「つまらない。リアルタイムに配置できない。ただ真っ直ぐ。この企画の面白さがない」。前回の完了は機能検証に偏り、プレイ価値の受入を満たさなかった。本計画が2026-09-20版の戦闘仕様を置き換える。旧成果物を履歴として残す。

## SPEC
中心命題: **戦闘中に置いた塔が敵の道を変え、そこで生まれる密集と射程を利用して、その場で窮地を覆せる。**

単に3本の線を曲げるだけでは足りない。プレイヤーが道を形作れること、撃破で得た資金を同じ戦闘中に使えること、配置直後に道の変化が見えることを最初のwaveから提供する。

## ミニADR（独立反証前の案）
A: 戦闘中建設を解禁し、固定曲線マップに変更。操作は戻るが道を作る判断がなく、既存の単調さを十分に解消しないため却下。
B: 塔が通行障害物になる動的迷路TD。戦闘中建設/強化/移設/回収、分岐/合流、経路予告、群れの実攻撃に対する適応。採用候補。
C: 完全に別ジャンルへ変更。今回の具体的な不満を捨て、新たな面白さ仮説の検証まで遠回りになるため却下。

### 実装契約
- 12x8グリッド。入口(0,1)/(0,4)/(0,7)、コア(11,4)。固定障害物はcol4 rows0..3、col8 rows4..7。初期から迂回と合流がある。
- 固定障害物と塔を避ける4近傍BFS最短経路。各入口および出現済み生存敵の現在セル・次セルから出口への経路が残る場合のみ設置/移設できる。
- 敵の占有セルと移動中の両端への建設は禁止。移動中は次セルまで進み、セル中心で新しい道へ進む。テレポートしない。
- 戦闘中も建設/強化可能。新設塔は通常攻撃間隔分の起動待ち。強化は残CDを保持。
- 移設は準備中無料、戦闘中15C＋起動待ち0.8秒（既存CDより短くしない）。戦闘中回収70%、準備中100%。無限の無料往復による足止めを防ぎ、介入自体は許す。
- 入口/出口の列全体、固定障害物に建設不可。拒否理由を明示。ホバーで候補の経路と増減を見せる。
- 敵は出現元を維持しつつ合流し、緊急スローは出現元の群れ単位。対象群れとCDを表示する。
- 塔の索敵は出口までの残距離が短い敵を優先。射程と範囲攻撃は実XY距離。
- 適応はwave中の実際に与えたダメージを属性別に累計し、終了時に確定。売却/移設で記録が消えない。次waveの人数/耐性は準備中不変、経路だけ配置に従って変わる。
- 固定1/60ステップ、一時停止/保存/同条件再戦を維持。同条件とは建設・スキルの実行時刻も含む。

## 独立反証の採否（maze_design_critic）
- 無料移設の無限往復: 採用。戦闘中15Cを経路操作そのものに課金（ゲーム内通貨のみ）。売却損と別に制約。人間への追加料金はゼロ。
- 最長経路一択: 採用。経路長と射程を同時に見せ、長い分散配置/短い集中配置を同予算実戦比較する。
- 移設を原子的に検証: 採用。元除去＋先追加の最終盤面で到達性/占有を検査、失敗時に資金/CD/塔/fieldを変更しない。
- 移動のリセット禁止: 採用。cell/nextCellを保持、辺を進み切ってから新経路へ。残距離で索敵。
- 実攻撃量: 採用。耐性計算後の実HP減少量（過剰分除外）を塔種と出現元別に累計。減速寄与は集計に含まれないことを説明。
- 初見から変更資源: 採用。各wave開始に戦闘補給60C（1waveに1回、開始フェーズ遷移時のみ）。最初に準備資金を使い切ってもパルス1基を建設できる。4種類は常時解禁。
以上を反映してB案を確定。経路純粋関数/rendererを独立実装し、メインが戦闘・入力・検証を担当。


## 実装・検証記録
- maze.js/BFSと連続XY移動、campaignの戦闘中操作、mainの常設パレット、rendererの曲折/合流経路を実装。
- 毎waveの開始補給60C。迷路延長による射撃時間増を受け、敵HPに `1 + (wave - 1) * 0.30` を乗算。旧数値では12seedで単一属性/適応配置とも無被害全勝だった。
- 調整後12seed: パルスのみを継続配置するbotは1/12勝利、属性対応・再配置botは12/12勝利。これは調整に使用した戦略/seedの比較であり、人間の勝率の推定ではない。
- 同じwave4・seed・350Cで比較。basic7基ではseed42の最長路偏重が被害10、射程集中が8。heat1+cold1+basic3では長い合流路が被害6、短い集中路が11（seed1では4対6、seed7では0対7）。塔構成により有利な配置が逆転する。`maze-placement-balance.json`参照。
- 300Cの装甲対策比較12seed平均被害: パルス23.67、フレアを有効経路に配置17.42、フレアを弱い位置に配置23.17。別々の配置も変化する実戦例であり、属性だけを分離した因果推定ではない。
- ブラウザ操作で回収90Cの70%が62Cになる浮動小数誤差を発見。整数割合を先に掛け、90→63/150→105等の固定期待回帰を追加。
- スマートフォンで通知がスロー操作を遮る問題を修正（通知はpointer-events:none）。
- 旧記録とはキーを分離（gunpen-live-maze-v3）。異なるルールのスコアを比較しない。

## オーナープレイ後の区切り（2026-09-21）
