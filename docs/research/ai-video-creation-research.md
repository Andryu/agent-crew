# 調査レポート：手書き落書き風ショート動画をAIで作って収益化する

作成日: 2026-07-19
目的: 動画制作未経験のオーナーが、複数のAIを組み合わせて「カップル・日常・おもしろ系（人の生態）」の手書き落書き風ショート動画を制作し、収益化するための調査。

---

## 1. 結論サマリー

| 論点 | 推奨 |
|---|---|
| プラットフォーム | **TikTok・YouTube Shorts・Instagram Reels に同時投稿**（1本作って3ヶ所に出す）。収益の柱は YouTube Shorts |
| 日本か海外か | **まず日本語で開始し、セリフを字幕中心に設計して英語版を並行投稿**（英語圏の広告単価は日本の2〜3倍） |
| 制作方式 | 手書きキャラ1セットを自分で描き、動き付け・台本・音声・編集はAIに任せる |
| 初期費用 | **月0円で開始可能**。軌道に乗ったら月3,000〜6,000円程度の有料プラン |
| オーナーが作るもの | ①キャラの元絵（初回のみ）②ネタの種（実体験メモ）③最終チェック。それ以外はAI |

---

## 2. プラットフォーム比較（2026年時点）

### 収益化の条件と単価

| プラットフォーム | 収益化条件 | 100万再生あたりの目安 |
|---|---|---|
| YouTube Shorts | 登録者1,000人＋直近90日間のショート視聴1,000万回 | 約1.5〜3万円 |
| TikTok (Creator Rewards) | フォロワー1万人＋直近30日間の視聴10万回 | Shortsよりやや低い傾向 |
| Instagram Reels | 日本では再生数連動の恒常的な報酬プログラムが限定的 | 案件・誘導向き |

ポイント:
- **広告分配だけでは大きく稼げない**（Shortsは1再生0.015〜0.02円程度）。実際の収益の柱は、再生数が育った後の「案件・アフィリエイト・グッズ・LINEスタンプ化」など。
- ショートフィード広告収益はプール後にクリエイターへ45%分配される仕組みで、長尺動画（55%）より低率。長期的には人気キャラを長尺・グッズへ展開するのが定石。
- 日本市場ではYouTube浸透率が高く30代以上に強い。若年層・トレンド拡散はTikTokが強い。**カップルあるある系は両方の層に刺さるため同時投稿が最適解。**

### 日本向けか海外向けか

- 米国など英語圏の視聴はRPMが日本の2〜3倍（100万再生で日本向け10〜25万円に対し英語圏向け30〜75万円という試算）。
- ただしエンタメ・アニメ系はもともと単価が低〜中のジャンルなので、単価差より**視聴母数の大きさ**が海外展開の主なメリット。
- 「カップル・人の生態あるある」は言語より状況で笑わせやすいジャンル。**セリフを最小限＋字幕で見せる設計**にすれば、字幕差し替えだけで英語版が作れる。
- 推奨: **日本語アカウントで型を確立 → 反応が良かったネタだけ英語字幕版を別アカウントで展開**（作業増はほぼ字幕翻訳のみ。翻訳もAIで完結）。

## 3. 「手書き落書き風でAIっぽくない」を実現するツール構成

このスタイル（自分ちの日常、落書きキャラの簡単な動き）は、実はAI動画の中でも**一番安く・簡単に・差別化しやすい**領域。フル生成AI動画（Sora風のリッチ映像）はAIっぽさが出るが、**「自分の手書き線をそのまま動かす」**ならAI臭が出ない。

### 工程別ツール

| 工程 | ツール | 料金 | 備考 |
|---|---|---|---|
| ネタ出し・台本 | ChatGPT / Claude | 無料〜 | 実体験メモを渡して30〜60秒の台本＋オチに整形させる |
| 絵コンテ | Canva（AI絵コンテ機能） | 無料 | 6〜8コマの簡易絵コンテ。慣れたら省略可 |
| キャラ・背景の元絵 | **自分の手書き**（紙＋スマホ撮影 or 無料お絵かきアプリ） | 無料 | ここが「AIっぽくない」の源泉。上手い必要なし |
| 元絵の量産・ポーズ違い | Nano Banana（Gemini）/ ChatGPT画像編集 | 無料〜 | 手書き1枚を渡して「同じ絵柄でポーズ違い」を生成 |
| 動き付け（簡単） | **Meta Animated Drawings** | 無料 | 手書きキャラに歩く・走る・踊る等を自動付与。落書きに最適 |
| 動き付け（リッチ） | Vidu / Kling（image-to-video） | 無料枠あり | Viduはスタイル化された絵に強い。Klingはキャラ参照機能で一貫性維持 |
| 音声 | **VOICEVOX**（無料・商用可 ※キャラ規約確認）/ ElevenLabs（Starter $5で商用可） | 無料〜$5 | ナレーション型ならVOICEVOXで十分 |
| 編集・字幕・SE | CapCut | 無料 | テンプレ・自動字幕・BGMまで一括。スマホ完結可 |
| BGM | YouTubeオーディオライブラリ / 各プラットフォームの商用音源 | 無料 | 商用可否を必ず確認 |

### AIっぽさを消すコツ
- ベースは必ず自分の手書き線（AI生成イラストから始めない）
- フレームレートを落とす（12fps相当のカクカク感＝手書きアニメらしさ）
- 紙テクスチャ・鉛筆線のゆらぎを残す
- 動きは「歩く・ずっこける・首をかしげる」程度のミニマムに留める（Animated Drawingsの得意領域）

## 4. 制作フロー（1本あたりの流れ）

```
① ネタ集め      … 日常の「あるある」を1行メモ（人間の仕事、常時）
② 台本化        … AIにメモを渡して30〜60秒の台本＋オチ生成（5分）
③ 絵コンテ      … AIで6〜8コマに分解（5分、慣れたら省略）
④ 素材準備      … 初回のみキャラ手書き。2本目以降はポーズ違いをAI生成（10分）
⑤ 動き付け      … Animated Drawings / Vidu に元絵投入（10分）
⑥ 音声          … VOICEVOX でセリフ・ナレーション生成（5分）
⑦ 組み立て      … CapCut で動画＋音声＋自動字幕＋SE（20分）
⑧ 投稿          … TikTok / Shorts / Reels に同時投稿（5分）
```

慣れれば**1本あたり実働1時間以内**。週3本ペースが現実的。

### 最初に準備するもの（初回のみ）
1. キャラデザイン: 主役カップル2人の手書き絵（正面・横・喜怒哀楽の表情数枚）。落書きレベルでOK
2. 世界観の統一要素: 線の色、背景の色、フォント（CapCutで固定テンプレ化）
3. アカウント: TikTok / YouTube / Instagram の3つ
4. ツールアカウント: ChatGPT or Claude、Canva、CapCut、VOICEVOX（すべて無料枠）

---

## 5. ロードマップ

| 期間 | やること |
|---|---|
| 週1 | キャラデザ確定・テンプレ作成・アカウント開設・試作3本（非公開でOK） |
| 週2〜4 | 週3本投稿。ネタの「型」を複数試す（会話型／ナレーション型／無言＋字幕型） |
| 月2〜3 | 伸びた型に集中。英語字幕版の並行展開を検討。TikTok収益化条件（フォロワー1万人）を目指す |
| 月4〜 | Shorts収益化条件到達→広告分配開始。案件・LINEスタンプ等の二次収益を検討 |

### コスト計画
- **開始時: 月0円**（全ツール無料枠）
- 本格運用: 月3,000〜6,000円（Vidu/Kling有料枠＋ElevenLabs Starter など、生成回数が足りなくなったら）

---

## 6. 注意点

- **無料プランの商用利用制限**: ElevenLabs無料枠は商用不可（Starter $5〜で解禁）。VOICEVOXは無料で商用可だがキャラごとの規約確認が必要。CapCutも商用利用規約を確認のこと。
- **音源の権利**: プラットフォーム提供の「商用楽曲ライブラリ」内の曲のみ使用する。
- **収益の期待値管理**: 広告分配は100万再生で数万円レベル。半年は「キャラと型を育てる期間」と割り切り、収益の本命は案件・グッズ展開に置く。
