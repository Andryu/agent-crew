# 人気タワーディフェンス分析 → 群変に取り入れること（2026-08-16）

対象: 群変（`docs/design/game-td-evolve-design.md`）の設計に反映するための、メガヒットTDと近年の少人数ヒットの分析。
選定基準: 売上・レビュー規模で実証済みのもの（Bloons TD 6 / Kingdom Rush / Plants vs. Zombies）＋ 少人数チームでの成功例（Thronefall）＋ 群変と同じ「周回」を売るローグライトTD（Rogue Tower / Isle of Arrows / Emberward）。

---

## 1. 各タイトルの「効いている部品」

### Bloons TD 6（Ninja Kiwi）— ジャンル最大のロングセラー
- 規模: Steam所有者200〜500万、レビュー38万件で97/100（圧倒的に好評）。同接は2024-08ピーク2.8万→現在7〜10千と、7年目でも生きている
- 効いている部品:
  1. **塔ごとに3系統×5段階のアップグレード**（＋Paragon）。「同じ塔でも自分の育て方」というビルド表現が周回の主燃料
  2. **敵に「解かせる」性質**: Camo（見えない）／Lead（物理無効）／Ceramic／MOAB級。「この性質にはこの塔」という対処パズルが毎ラウンド発生する
  3. **次ラウンドの内容が事前に見える**（ラウンド情報）→ 読んで備える面白さ
  4. **メタ進行**（Monkey Knowledge: レベルアップごとに1ポイント）、デイリーチャレンジ、ボスイベント、Odyssey、協力プレイ、サンドボックス。周回の「口実」を大量に用意
  5. **ポップの快感**: 風船が割れる音と粒子。撃破フィードバックが徹底して気持ちいい

### Kingdom Rush（Ironhide）— 「触っていて退屈しない」TDの完成形
- 効いている部品:
  1. **敵ごとに違う答えを要求**（飛行・高装甲・魔法耐性・高速・分裂…）。塔の選択に意味が出る
  2. **tier3で2つの全く違う上位分岐**。少ない塔数でもビルドが分かれる
  3. **ウェーブ中の能動介入**: ヒーロー操作／増援召喚／雨のように降る火。「置いて眺めるだけ」を壊す。**さらに「次のウェーブを早く呼ぶ」と資金ボーナス**（テンポ管理を報酬化）
  4. ボス戦は固有ギミックで「同じ倒し方が二度ない」
  5. ステージ×3つ星＋ヒロイック／アイアン挑戦モードで**同じマップの周回に別ルールを付ける**

### Plants vs. Zombies（PopCap／George Fan）— 母親でも遊べる可読性
- 効いている部品:
  1. **絵が機能を説明する**（ピーシューターは弾を吐きそうな顔）。言語なしでも遊べる可読性
  2. **1画面・固定レーン**（芝生5列）。状況把握が一瞬
  3. **テキストで教えない**。1レベルにつき新要素1つ、遊ばせながら学ばせる（GDC 2012「10のチュートリアル手法」）
  4. **資源（太陽）を拾う小さな能動行為**が退屈を消す
  5. テーマとメカニクスの結合（ひまわりが太陽を出す＝説明不要）

### Thronefall（Grizzly Games, 2人）— 「小さく作って完成させる」実証
- 規模: 初年度100万本（$12.99）、EA数ヶ月で31.5万本・返品率6.9%、**発売2ヶ月時点で35%以上のプレイヤーが5時間以上プレイ**
- 効いている部品:
  1. **ジャンルから脂身を全部落とす**（塔の種類も操作も最小）。残った本質だけを磨く
  2. **プレイヤー自身がユニット**として戦場を走る＝能動性の担保
  3. 短いセッション、レベルごとに**Perk／ミューテーターの組み合わせ**で周回を作る
  4. 開発側の教訓:「1〜3人チームでは小さく作ることだけが完成への道。最大の敵は完成しないこと」

### ローグライトTD群（Rogue Tower / Isle of Arrows / Emberward）— 「周回」の作り方
- 共通: **ランダム性が「配置の判断」を毎回作り直す**（タイル引き／テトリス壁／カード400枚）。通常TDは「一度クリアしたら戻る理由がない」問題を、これで解決している
- 注意: 周回の変化源がRNGドラフトに寄ると「進化」という群変の看板が薄まる。群変の変化源はあくまで敵の進化。RNG要素は足すとしても補助に留める

## 2. 横断して見える共通パターン

| # | パターン | 実装している作品 | 群変での現状 |
|---|---|---|---|
| P1 | **次に来る敵が事前に読める**（ラウンド情報／ウェーブアイコン） | BTD6, KR, PvZ | 変異レポートは「終わった後」だけ。**来る前**が無い |
| P2 | **敵に性質があり、対処が塔選択に直結** | BTD6, KR | 耐性遺伝子で実装済み（○） |
| P3 | **ウェーブ中の能動介入手段** | KR（スキル/ヒーロー）, Thronefall（自機）, PvZ（太陽拾い） | 配置・売却のみ。**オーナー指摘「介入が薄いのは微妙」と直結** |
| P4 | **塔のアップグレード＝ビルド表現** | BTD6, KR | 無し（4種置くだけ） |
| P5 | **撃破フィードバックの快感** | BTD6, PvZ | SE4種のみ。撃破の見た目演出が未定義 |
| P6 | **テキストで教えず、遊ばせて教える** | PvZ, Thronefall | チュートリアル未定義 |
| P7 | **同じ条件に別ルールを付けて周回させる** | KR（ヒロイック/アイアン）, Thronefall（perk）, BTD6（デイリー） | チャレンジリンクのみ |
| P8 | **テンポの報酬化**（早出しボーナス） | KR, BTD6 | 無し |
| P9 | **ボスウェーブ**（固有ギミック） | KR, BTD6 | 無し |
| P10 | **小さく作って完成させる** | Thronefall | 14日・塔4種・1マップ（○） |

## 3. 群変に取り入れること

### v1（14日）に入れる — 各0.5〜1日、合計+2日程度。テーゼ「進化が知覚されるか」を**強める**ものだけ選んだ
1. **次ウェーブ・プレビュー（P1）**: 配置フェーズに「次に来る群れ」の代表個体を5体、見た目付きで表示（進化後の集団からサンプリング）。**進化を「事後レポート」だけでなく「事前の脅威」として見せる**。BTD6のラウンド情報／KRのウェーブアイコンの群変版。進化の知覚に最も効く1手
2. **能動スキル1つ（P3）**: 「発熱」— 指定レーンの個体を3秒間 速度50%（クールダウン30秒、ウェーブ中のみ）。介入の薄さへの直接回答。塔と同じ属性ルール（凍耐性には効きが半減）で一貫性を保つ
3. **塔のアップグレード2段階（P4）**: 各塔 Lv1→Lv2→Lv3、費用は初期費用の80%/120%、ダメージ+40%/+40%・射程+0.3。分岐なし。「置いた塔を育てる」最低限の表現。進化した群れへの追随手段が増え、軍拡の往復が太くなる
4. **早出しボーナス（P8）**: 配置フェーズで即「ウェーブ開始」を押すと+15資金。テンポの良い人が報われる。0.5日
5. **撃破ジュース（P5）**: 撃破時に個体の色で破裂粒子（6〜10個）＋資金の小さな数字ポップ。既定のSEに乗せる。0.5日
6. **教えない導入（P6）**: 初回のみ、ウェーブ1前に吹き出し1つ「塔を置いて、ウェーブ開始」。ウェーブ2の変異レポート初回表示に一行「群れは、あなたの守り方に合わせて変わります」。それ以上の説明はしない

### v2（プレイテスト結果次第）
- **ボスウェーブ（P9）**: ウェーブ5/10/15に「その世代の最優秀個体の巨大版」を1体混ぜる。体格遺伝子の延長で実装でき、「進化の到達点を見せる」演出になる。v1.5候補
- **デイリーseed（P7）**: 日付からseedを決めるだけ（サーバなし）。「今日の群れ」を全員が同条件で遊べる。チャレンジリンクと同じ仕組みで実装は0.5日だが、届け方の効果測定を分散させないためv1では入れない
- **ミューテーター／別ルール周回（P7）**: 「初期資金半分」「塔3種のみ」「突然変異率2倍」。KRヒロイック／Thronefall perkの群変版
- **分岐アップグレード（P4拡張）**: Lv3で2択（範囲寄り／単体寄り）
- **メタ進行**: 初クリアで塔5種目を解放、など。テーゼから遠いので慎重に

### 取り入れない（意図的に）
- 塔の種類増・マップ増・ヒーロー・カード400枚: コンテンツ量で勝負しない（Thronefallの教訓、テーゼ違反）
- RNGドラフト（Rogue Tower型）: 変化源が「進化」でなくなる
- 協力・対戦のリアルタイム同期: サーバなし方針
- ガチャ・課金設計（Arknights等）: 対象外

## 4. 設計文書への反映
`docs/design/game-td-evolve-design.md` に「人気TD分析からの追加仕様」節を追加（v1追加6項目の確定仕様＋DoD追記、v2候補は列挙のみ）。14日工程は D4-7 に「プレビュー・アップグレード・スキル」、D8-10 に「ジュース・早出し・導入」を配分し、全体+2日は D11-14 のバランス調整枠を圧縮せず**16日目安**に伸ばす（Thronefall教訓: 完成が最優先。詰め込んで未完で終わらせない）。
