# EP01 制作台本・絵コンテ「初ハウステンボスで彼氏が天然すぎた話」

尺: 約45〜50秒（ショート動画）
型: ナレーション型（彼女視点モノローグ＋字幕）— 音無し視聴でも字幕だけで伝わる設計。英語字幕版への転用も容易。
音声: VOICEVOX（彼女ナレーション1名分のみ。彼のセリフは「！？」等の字幕とSEで表現）

## 3. 素材リスト

### 既にある素材（受領済み）
- 彼女: 顔アップ／全身（腕あり版）
- 彼: 顔アップ／全身（腕あり版）

### 追加で必要な素材と作り方

| 素材 | 作り方 | 担当 |
|---|---|---|
| 彼の横向き・覗き込みポーズ | 全身版をNano Banana / ChatGPTに渡し「同じ落書きタッチで横向きに覗き込むポーズ」で生成 → style が崩れたらオーナーが描き直し | AIまず→ダメなら人間 |
| 女子グループ（モブ2〜3人） | 超簡略の棒人間でOK。AI生成 or 30秒の手描き | どちらでも |
| カメラ＋三脚の小物 | 落書きで三角＋丸だけ。手描き推奨（30秒） | オーナー |
| 傘いっぱいの背景 | カラフルな丸をランダムに並べるだけ。AI生成（同タッチ指定）も可 | AIまず |
| 風車・街並み背景／観覧車（丸＋ゴンドラ） | 同上。ざっくりでいいのでAI生成→違和感あれば手描き | AIまず |
| VRゴーグル顔（2人分） | 既存の顔絵に黒い長方形を乗せるだけ。CapCut上で加工可 | 編集で対応 |

### 音
- ナレーション: VOICEVOX（キャラは試聴して彼女のイメージに近いものを選ぶ。商用規約を確認）
- SE: CapCut内蔵（「じーっ」の無音→時計音、ガーン、ヒュー）
- BGM: 投稿先プラットフォームの商用ライブラリから穏やかなワルツ系（テーマパーク感）

## 4. 制作手順チェックリスト（このエピソードでの実働目安）

1. [ ] ポーズ違い・背景素材をAI生成（Nano Banana / ChatGPT画像）— 20分
2. [ ] Animated Drawings で「歩く」「jump」「wave」の3モーションを書き出し — 15分
3. [ ] VOICEVOX でナレーション9行を生成 — 10分
4. [ ] CapCut で絵コンテ順に配置＋自動字幕＋SE＋BGM — 40分
5. [ ] 書き出し 9:16・1080p → TikTok / Shorts / Reels に同時投稿 — 10分

初回はツールに慣れる時間込みで半日想定。2本目から1時間台を目指す。

### 演出メモ
- カット5の「間」が本命の笑いどころ。ナレーションを止めて時計のSEだけにする。
- 12〜15fps相当のカクカク感を維持（CapCutで滑らかにしすぎない）。
- 字幕フォントは丸ゴシック系で手書き感を統一。1本目からテンプレ化して使い回す。
