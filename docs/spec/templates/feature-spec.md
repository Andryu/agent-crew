# 機能仕様書テンプレート

> **使い方**: この機能を新規実装する、または既存機能に変更を加える際、
> `docs/spec/features/<機能名>.md` としてコピーし、以下の4セクションを埋める（or 更新する）こと。
> **本体は「概要」「ユースケース」「仕様（現在の正）」の3つを常に最新に保つ living document とし、
> 過去の経緯は「変更履歴」にのみ残す**（本文に古い設計判断を残さない）。
>
> 対象規模: 1機能1ファイル。requirements/design/tasksの3点セット分割は行わない
> （ADR-015参照。個人開発の規模では過剰）。
