02

まだ決まっていない3つの軸

このページの点線枠は、すべて「まだ決まっていない」の印。決まった瞬間に何が確定するかを併記した。

① 寝室の大人の寝具は、ベッドか布団か

添い寝型ベビーベッドは大人のマットレス高さに床板を合わせる構造なので、この一点で候補が入れ替わる。

ベッドなら → ファルスカ ベッドサイドベッド03（高さ9段階）が本命。
布団なら → 高さ調整の意味が薄れ、ココネル エアー AB の省スペース性が効く。

② ベビーベッドをミニにするか、レギュラーにするか

①の帰結でもある。ココネル エアー系はミニ専用布団しか使えないため、ここが布団の型番まで規定する。

ミニ（60×90）なら → サンデシカ8点セット ミニ / un doudou 9点セット。
レギュラー（70×120）なら → サンデシカ8点セット レギュラー / 西川7点セット。

③ 保育園を0歳4月入園で狙うか

Notion上の本命は2028年4月入園。もし2027年4月（0歳）に切り替えるなら、ベビーカーの購入時期が2月では遅くなり、慣らし保育に間に合わせる必要が出る。

2028年4月のままなら → ベビーカーは2027年2月で問題なし。
2027年4月に前倒すなら → ベビーカーを1月中に確定させる。

自家用車の有無は、この5点には影響しない

チャイルドシートは今回の対象外。タクシー等の旅客運送事業の車両は道交法上のチャイルドシート着用義務の適用除外にあたるため、退院時の移動手段としてタクシーを使う限り、この判断は5点の買い物を止めない。

価格情報の訂正。引き継ぎ資料にある「ココネルエアープラス AB 約2.2万円」は、確認した限り無印の「ココネル エアー AB」の実売価格にあたる。「プラス」は公式で税込¥36,300（税抜¥33,000）で、差分はマットを洗濯機で丸洗いできる点。2.2万円の想定でプラスを買いに行くと1.4万円ぶん足りない。どちらを買うかを先に決めること。

産後ケア・家事代行

★★★★3–10万円申請は10月下旬〜

5点で唯一の「物ではない」買い物であり、唯一、申請期限で機会が消える買い物でもある。里帰りをしない以上、ここは削るところではない。

妊娠28週＝2026-10-24 から申請できる

江戸川区の産後ケア事業は妊娠28週（8か月）から利用申請を受け付けている。予定日2027-01-16 から逆算すると2026年10月24日。買い物リスト上は「11月」だが、申請だけは10月下旬に前倒しできる。枠には限りがあるので、抱っこ紐の試着と同じ月に済ませてしまうのが良い。

エポスプラチナ 100万円修行との噛み合わせ

集計期間の締切は2026-10-30、不足は約36万円。締切が「利用日」か「売上確定日」かで駆け込みが飛ぶため10月20日を実質締切とすると、このタイムラインで10月に乗せられるのは抱っこ紐（2〜4万円）のみ。ベビーベッドと布団を10月に前倒せば+4〜8万円だが、ベッドは「大人の寝具」の判断待ちで、布団はベッド待ち。判断を急がせてサイズを間違えるほうが高くつくので、修行の穴埋めは買い物以外（保険の年払い・つみたて・支払い集約）で埋めるのが筋。なお出産費用60万円前後は次の集計期間に落ちるため、次期の達成は放っておいてもほぼ確定する。
