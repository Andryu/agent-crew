# 個人共通作業契約

- 説明・コメント・連絡は日本語で行い、技術用語と識別子は元の形式を維持する。
- 依頼の目的に必要な調査・編集・関連テスト・失敗修正は、許可された範囲で自走する。
- 未追跡を含む既存変更を保持し、他者の作業を上書き・破棄しない。
- commit・push・PRなどは依頼された範囲で実施し、既に許可された操作を再確認しない。
- 依頼外の破壊的操作・外部送信・global設定変更は、対象と影響を具体化して確認する。
- 完了時は実ファイル・Git・テスト結果を根拠に、変更・検証・残る制約を報告する。
- repo固有の作業条件と引継ぎ・保存入口は、対象repoのAGENTS.md等の契約に従う。
