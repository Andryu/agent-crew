# 旅行スキルセット

claude.ai（デスクトップ/Web）で使う旅行関連スキル。**マスターはこのagent-crewリポジトリで管理し、claude.aiのスキル設定へは各 `SKILL.md` 全文を貼って同期する**（自動同期はないので、ここを更新したらclaude.ai側にも貼り直すこと）。

| スキル | 役割 |
|--------|------|
| `travel-itinerary-artifact/` | プランを**作る**。ヒアリング→プランニング→導線→予約→お土産→アウトプット（アーティファクト+Funliday取り込み用テキスト） |
| `travel-plan-review/` | 完成したプランを**検査する**。実在・営業／導線／制約適合／タイムバジェット／予約／リスクの6観点監査。🔴🟡🟢で報告 |

作る側と検査する側を分けているのは、作った本人（同じ会話のClaude）は自分のプランの穴に気づきにくいため。レビューは**別会話**で travel-plan-review を起動して依頼するのが効果的。

※Claude Codeのセッションにもスキルとして読み込まれるが、本文は claude.ai 専用ツール（`places_search` / `create_file` / `present_files`）前提。Claude Codeで旅行相談をする場合は WebSearch 等で代替する。

## 未検証事項（スマホで一度試すこと）

FunlidayアプリのAIプランナー入力欄に、下のサンプルを貼ってマップ化されるか確認する：

```
■ 箱根 2泊3日
【1日目】
09:00 小田原駅
10:00 はつ花そば 本店
13:00 箱根神社
15:30 箱根湯本温泉 ホテルおかだ（宿泊）
```

- **通った場合** → この出力形式で運用開始してよい。SKILL.md 5-2 の「実機未検証」注記を削除する
- **通らなかった場合** → スポット名の1件ずつ検索追加が確実な代替。結果をClaudeに伝えれば 5-2 の手順を書き換える
- ついでにClaudeの会話共有URL（`claude.ai/share/...`）をURL欄に貼る実験も価値あり。通れば手順を大幅簡略化できる
