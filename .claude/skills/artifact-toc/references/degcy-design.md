# デジタル庁デザインシステム参考ガイド（Artifact用）

Artifact（HTMLページ）のデザインで参考にする値と原則。
出典: デジタル庁デザインシステムβ版（design.digital.go.jp/dads/）。
**注意: 以下は本ガイド作成時点の代表値。実装時に公式サイトで最新値を確認すること**
（このリポジトリの環境からは design.digital.go.jp に直接アクセスできない場合がある）。

## タイポグラフィ

- フォント: 本文・見出しとも **Noto Sans JP**（オープンソース・Webフォント利用可）。等幅は **Noto Sans Mono**
  - Artifactは外部フォントCDNが使えないため、システムフォントスタック
    `"Hiragino Sans", "Noto Sans JP", "Yu Gothic", Meiryo, sans-serif` で代替してよい
- 本文サイズ: **16px以上**（12px未満は使わない）
- 行間: 本文 **1.7**、見出し 1.4〜1.5
- 1行の長さ: 全角40字前後（max-width で制御）
- 見出しは階層を飛ばさない（h2の次はh3）

## カラー（代表値）

| 役割 | 値 | 備考 |
|---|---|---|
| プライマリ／リンク | `#0017C1`（Blue-900） | 政府系の濃い青。リンクは下線付き |
| テキスト | `#1A1A1C` | 純黒ではない |
| エラー | `#EC0000` | |
| 背景 | `#FFFFFF` / 淡グレー | |
| ボーダー | グレー系（`#949497` 前後） | |

- 色だけで意味を伝えない（アイコン・ラベルを併用）
- コントラスト比: 本文 **4.5:1以上**、大きな文字 3:1以上（WCAG AA）
- ダークテーマを用意する場合も上記コントラスト基準を守る

## スペーシング・レイアウト

- **8pxグリッド**（8/16/24/32/40…）で余白を組む
- タップ・クリック領域は最小 44×44px
- 角丸・影は控えめに（過剰な装飾をしない）

## アクセシビリティ

- キーボードフォーカスを必ず可視化（`:focus-visible` にアウトライン）
- SVG図には `role="img"` と `aria-label`
- テーブルには `th`、図には `figcaption`

## 適用方針

- **原則（タイポグラフィ・余白・コントラスト・アクセシビリティ）は常に踏襲する**
- カラーはプロジェクトの文脈に合わせて調整してよいが、コントラスト基準と
  「色だけで意味を伝えない」は守る
- 迷ったら「読みやすさ優先・装飾は最小限」がデジタル庁デザインシステムの精神
