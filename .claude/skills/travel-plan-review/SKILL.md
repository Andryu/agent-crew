# 旅程レビュースキル

完成した旅程を「その通りに動けるか」の観点で監査する。作った本人（AIを含む）は自分のプランの穴に気づきにくい。このスキルの価値は、プラン作成時の思い込みを事実で検証し直すことにある。したがって**レビュー対象のプランを作った時の前提を引き継がず、ゼロから検証する**こと。

## レビューの進め方

まずプラン全体を読み、旅行の基本情報（日程・同行者・宿・移動手段）と同行者の制約（妊娠中・高齢者・子連れ等）を把握する。制約が書かれていないプランをレビューするときは、先に「同行者に体力・食事の制約はあるか」を確認する——制約の有無でレビュー結果が大きく変わるため。

その上で、以下の6観点を順に検査する。

### 1. 実在・営業検証

- プランに登場する店・施設のうち、行程の柱になっているもの（食事場所・目玉スポット・予約前提の施設）を `places_search` と `web_search` で再検証する
- **訪問予定の曜日・時刻と定休日・営業時間を突き合わせる**。「営業している」だけでは不十分で、「その日その時刻に開いているか」まで確認する（ランチ営業のみの店に夕方到着する、月曜訪問なのに月曜定休、など典型事故）
- 臨時休業・閉店・移転の兆候（口コミの最新日付が古い、公式SNSが止まっている）があれば正直に「不確実」と報告し、電話確認を促す

### 2. 導線の物理的整合

- 各移動区間の所要時間を座標ベースで再計算し、プラン記載の時間と突き合わせる。乗換・待ち時間・バスの本数（1時間に1本の路線で乗り継ぎ5分は破綻）まで見る
- チェックイン/チェックアウト時刻と行程の整合、荷物を持ったまま観光する区間がないか
- 「その通りに歩けない」区間（山道・階段・積雪期の徒歩など、地図上の距離だけでは見えない障害）に注意する

### 3. 制約適合

- 同行者の制約と各行程を1つずつ突き合わせる。妊娠中・高齢者・子連れなら徒歩15分超の区間、長時間の立ちっぱなし、休憩なしの連続行動をフラグする
- 子連れの場合はさらに、ベビーカーで通れない導線（階段のみの駅・砂利道）、授乳・おむつ替え施設の空白区間、昼寝・食事の時間帯を無視した行程、子どもが食べられるメニューの有無をフラグする
- 食事制約（アレルギー・生もの不可等）と各食事場所のメニューの相性。「その店で食べられるものがあるか」まで確認する
- 譲れない予約（18:30ディナー等)から逆算して、前の行程が間に合うか

### 4. タイムバジェット

- 各スポットの滞在時間が現実的か（美術館30分は短すぎる、など施設の標準所要時間と比較）
- 食事時間が確保されているか、ラストオーダー・最終バス・最終ロープウェイに間に合うか
- 詰め込みすぎの日がないか。1日の総歩行時間・総移動時間を概算し、同行者の体力と照らす

### 5. 予約・金銭

- 要予約なのに予約の記載がない項目（繁忙期の新幹線指定席・人気店・時間指定チケット）を洗い出す
- 予約開始日がまだ先のもの、キャンセル期限が近いものをカレンダー的に整理する
- 概算予算感に大きな見落とし（往復交通費・宿以外の高額項目）がないか

### 6. リスクと代替

- 雨天時に成立しない行程（屋外のみの日）にPlan Bがあるか
- 体調不良時に削れる行程・短縮ルートが用意されているか
- 混雑・行列で時間が読めないスポットが行程のクリティカルパス上にないか

## 報告形式

必ずこの構成で報告する：

```
# 旅程レビュー結果: {プラン名}

## サマリー
（1〜2文。致命的問題の有無と総合所感）

## 🔴 致命的 — このままでは行程が破綻する
## 🟡 要注意 — 不確実・確認を推奨
## 🟢 改善提案 — 良くなる余地
（🔴🟡🟢とも、該当なしのセクションは省略せず「なし」と明記する）

## 検証済み事項
（問題なしと確認できた項目。何を検証したかを残す）
```

- 1つの指摘は「**事実**（何が問題か）→ **根拠**（検証結果・出典）→ **修正案**（具体的にどう直すか）」のセットで書く。根拠のない印象論は書かない
- 問題がなかった項目も「検証済み」に残す。レビューの網羅性が読み手に伝わり、「見ていない箇所」との区別がつく
- 修正案を出しても**勝手にプランを書き換えない**。修正の実施を依頼されたら travel-itinerary-artifact スキルの手順（変更の波及再計算）に従って直す

## よくある落とし穴

- **褒めるだけのレビューは無価値**: 指摘ゼロで返すときは、その分「検証済み事項」を厚くして何を確認したかを示す。検証せずに「問題ありません」と言うのが最悪
- **プラン作成時の検証結果を信用しない**: 「作成時に営業確認済み」と書いてあっても、レビュー時点で再確認する。作成とレビューの間に状況が変わることは普通にある
- **制約の見落としが最重度**: 導線や時間の誤差は現地でリカバーできるが、妊娠中の同行者に生もの前提の食事場所、高齢者に長い山道、は現地でのリカバーが難しい。観点3は最も慎重に
- **重箱の隅と致命傷を同じ温度で報告しない**: 🔴🟡🟢の分類を厳密に。全部🟡にするのは判断の放棄
