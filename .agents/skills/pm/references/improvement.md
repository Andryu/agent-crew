# 教訓からの改善候補

依頼された改善分析では、出典と既存対策の状態を確認して次を探す。

| パターン | 確認の目安 | 提案につなげる判断 |
|---|---|---|
| カテゴリ集中 | 同カテゴリ3件以上 | 個別修正ではなく共通工程に原因があるか |
| 繰り返し | `frequency_score >= 2` が複数 | 対策未実施・対策不奏功・誤診断を区別する |
| 高優先度の未対処 | `priority_score >= 6` で未起票 | 証拠と着手条件が揃っているか |
| 対策の重複 | 類似する推奨アクションが複数 | 一つの変更で解消できる根因が共通するか |

目安への一致だけで構造的問題と断定しない。提案はタイトル、対象教訓と出典、優先度の根拠、改善内容、効果の検証条件、未決事項を示す。

分析結果とIssue発行・通知・教訓の保存は別の作業である。提案した件数を発行済みと報告しない。自動的な定期実行や外部送信はこの資料の範囲に含めない。
